## Why this release

Russian has **6 grammatical cases** (nominative, genitive, dative, accusative, instrumental, prepositional). A single noun like "Karazhan" can appear as `кара`, `кары`, `каре`, `кару`, `карой`, `кары` — same word, six different byte sequences that a token-matching dictionary sees as different.

Before v0.8.0 the dictionary covered roughly 3–4 forms per key noun. This release fills in the rest for every high-frequency category.

## Categories with full case coverage now

- **Instances/raids**: Karazhan, Gruul, Magtheridon, Hyjal, Serpentshrine, The Eye, Zul'Aman, Arcatraz, Botanica, Mechanar, Ramparts, Mana-Tombs, Magisters' Terrace, Underbog, Slave Pens, Sethekk Halls, Steamvault
- **Classes** (singular + plural, all cases): mage, hunter, paladin, warlock, shaman, priest, rogue, warrior, druid
- **Roles**: tank, healer
- **Gear slots**: cloak, weapon, ring, shield, armor, helm, pants, belt, boots, gloves, shoulders, bracers, neck, trinket
- **Stats**: strength, agility, intellect, stamina, crit, haste, hit, spell power, resistance, rating
- **Top-20 verbs**: past-tense m/f/pl + present 1st/2nd/3rd person + imperative + future (быть, идти, делать, мочь, знать, хотеть, видеть, слышать, помогать/помочь, дать, купить/покупать, продать/продавать, искать, найти, ждать, говорить/сказать, писать/написать, думать, помнить, ходить, брать/взять, убить, играть, качаться)
- **Adjectives**: good, bad, cool, new, old, big, small, strong, weak — all cases
- **Numerals** 1–10, 20, 30, 50, 100, 1000 — all cases (одного, двух, трёх, пяти, десяти, ста, тысячи…)

## Size

- **3261 → 3814 entries** (+553)
- File ~140 KB (was ~100 KB)
- Memory impact under 1 MB per `GetAddOnMemoryUsage`. Practical architectural limit is ~20 000 entries before anything slows down; we are at 19 %.

## Coverage

All six existing chat logs still at **98 %**. Benefit of this release is future-facing — new sessions will no longer miss inflected forms of words already in the dictionary.

## Install

Extract `wow243-russiantranslator-v0.8.0.zip` to `<WoW 2.4.3 install>\Interface\AddOns\`.
